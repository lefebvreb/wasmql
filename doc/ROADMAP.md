# WasmQL Roadmap

First off, PRs and Issues are always welcome.

I don't plan on working on WasmQL again in the near future, but in the rare case of it gaining traction, I will come back to it.

In particular, here a few points that I would like to address first:

* Support for i128/u128 to Bigint in (de)serialization with JS.
* A TypeScript bindings generator.
* Optimizations: in particular, chunking the serialization of bytes to a JS ArrayBuffer.
* A npm package for better integration with frontend projects.
